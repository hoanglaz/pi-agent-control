# Security policy

Do not report vulnerabilities in public issues. Contact the repository maintainers privately through the GitHub Security Advisories feature once a public repository is established. This repository currently has no public security contact or published release.

The extension executes inside the Pi host and inherits its permissions. It uses documented same-process runtime messages and user-selected task/model inputs. It does not write credentials or configuration. Please avoid attaching API keys, OAuth tokens, private prompts, or session logs to reports.
